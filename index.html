Pipeline de Indicadores Macroeconômicos (BCB)

Pipeline de engenharia de dados automatizado que consome séries temporais (Selic e IPCA) da API do Banco Central do Brasil, realiza limpeza/tratamento com Python e persiste os dados estruturados no PostgreSQL via Apache Airflow.

📐 Arquitetura da Solução

API BCB ➔ Airflow (ETL Python) ➔ PostgreSQL (Data Warehouse) ➔ Metabase Dashboard
